## 一、起因与目标

现状缺口：团长对用户的沟通散落各处——§五协作规则只有一句"每阶段通报"，澄清规则在 §6.4、决策呈交在 §6.5、需求确认在 G-1，没有统一规范。风险：阶段内过程噪音刷屏、追问挤牙膏、汇报无结论前置。

用户诉求方向："多问问题，但别啰嗦"——**开工前问清（G-1 已解决），过程中少打扰、一次问清、汇报给结论**。

目标：新增 §3.4，把团长↔用户的沟通固化为可执行的节奏、提问规格、汇报格式与交付呈现规范。
