# PR-031：会话积分消耗报告（按模型归集团员积分）

- **日期**：2026-11-17
- **版本**：1.4.4 → 1.4.5
- **性质**：能力新增（成本可视化）
- **触发**：用户要求「把每次对话活动不同类型模型消耗的积分输出出来」。

## 能力定义

新增 `scripts/credit_report.py`：从本地会话转录（主转录＋团员子转录）读取两类第一手数据并输出报告——
1. **团员积分**（平台逐笔记账的 credit-usage 事件，来源=team_member）：按时间窗归属到团员，团员所用模型取自其子转录，聚合成「各模型积分表」；顺序运行的团员精确归属，并行期无法唯一归属的记「未归属」，不猜；
2. **token 用量**：团长与各团员的输入／输出／缓存命中／请求数，按模型分组。

## 数据事实（探查确认）

- 平台对团员请求逐笔记账（credit-usage 事件带数值），但事件本身不带模型名——模型信息在消息层的请求标识中，靠时间窗关联；
- 团长自身请求的积分不逐笔记入会话转录（如实标注，以账单为准）；
- 团员子转录位于会话目录 subagents/ 下，含各自模型与用量。

## 验证

- 以本会话真实数据跑通：mat（GLM-5.3）17.74 积分 3 笔、ver（DeepSeek-V4-Pro）48.08 积分 11 笔，合计 65.82 积分；与逐笔明细人工核对一致。
