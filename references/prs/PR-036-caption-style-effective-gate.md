# PR-036 角标类样式"真正生效"闸门（2026-11-19）

## 问题
用户反馈：「角标-表格」「角标-图片」也出现"只套用了样式、字体没改过来"——题注段落挂上了角标样式，但字体字号仍是旧的黑体 10.5 磅，样式定义的仿宋 12 磅不生效。

## 根因
与 PR-034 同源，发生在题注类样式上：`build_docx.py` 渲染表题/图题时先建 run 并写死直接格式（`cr.bold=True`、`cr.font.size=Pt(10.5)`、`_set_run_font(cr,"SimHei","黑体")`），随后 `make_docx.py` 才把段落样式换成「角标-表格」/「角标-图片」。样式只在没有直接格式时说了算——文字级 `rFonts/sz/szCs` 一旦存在，就盖掉样式继承的仿宋 12pt。
自检未拦下的原因：`doc_selfcheck.py` 的样式生效判据只覆盖「居中-表格」与图片段，未覆盖角标类；且"表题数=表数"原用"≥"判定，题注多套也能通过。

## 修复
- `scripts/build_docx.py`：表题与图题改为**只套样式、不写任何直接格式**（「角标-表格」/「角标-图片」），仅当模板缺该样式时才降级为直设黑体 10.5pt。
- `scripts/make_docx.py`：新增 `strip_caption_fonts()`，对「角标-表格」「角标-图片」段统一剥离直接字体字号并计入出件摘要。
- `scripts/doc_selfcheck.py`：新增两项可数判据（表题角标、图题角标直接字体字号数=0），自检 14 项增至 16 项；「表题数=表数」由"≥"收紧为**严格相等**，题注多套同样判不合格。
- `scripts/fix_docx_styles.py`：扩展为可对已生成文档剥离角标类直接格式。**不做题注补套**——实测按"表格/图片前一段"补套会把"…如下表。收口判据全部为可数条件"这类引导句误判为表题，凭空给正文加"表 N"编号，故补套一律回到文档树重渲。
- `references/word-template-style-spec.md` §6.7.3：增第 ⑦ 条校验要求。
- `agents/docx-agent.md`：交付纪律 14 项改 16 项，新增 PR-036 硬规则与两条可数判据。

## 验证
- 修复前产物取证：5 段「角标-表格」均带 `w:rFonts` + `w:sz` 直接格式，自检报 FAIL。
- 用扩展后的修复脚本处理同一份：剥离 10 处直接格式，自检转 OK。
- 反例测试（为何不自动补套）：补套逻辑把 3 段引导句误判为表题，角标段从 5 涨到 8——已据此移除补套能力。
- 从文档树重新渲染：`make_docx.py` 摘要「角标段 5 剥离直接字体字号 0 处」，十六项自检全通过；样式继承链实测为「角标-表格/角标-图片 → 居中-图片（12pt）→ Normal（仿宋）」，直接格式残留 run 数 0。

## 结论
样式合规判据从"居中-表格 + 图片段"扩展到"全部带样式即应生效的段落"：居中-表格、居中-图片、角标-表格、角标-图片四类均以"直接格式数=0 + 读回生效值"为闸门。题注不靠版面猜测补套，只从文档树重渲。
