## 四、设计要点（核心机制）

> 设计目标：**区分"真锚点"与"张冠李戴"，且避免度量反噬**（低覆盖不全等于错锚）。

### 4.1 特征抽取
- **中文 2-gram**：对引用主题句与原文区间分别抽 2-gram，剔除虚词 `STOP_BIGRAMS` 与噪声正则 `RE_NOISE`（§锚点 / v版本 / Ch章 / 行号 / 裸数字 / markdown 标记）。
- **英文·数字术语 token**：抽取 ≥3 字母的术语（如 `mock` / `fallback` / `Whisper` / `RTP`），作为跨语言锚点。
- **覆盖率** = `| 主题特征 ∩ 原文特征 | / | 主题特征 |`。

### 4.2 判别阈值（产线标定，非拍脑袋）
| 常量 | 值 | 含义 |
|------|----|------|
| `PASS_COVERAGE` | 0.18 | ≥ 判 PASS |
| `WARN_COVERAGE` | 0.08 | `[WARN, PASS)` 判 WARN；`<` 判 ERROR（张冠李戴嫌疑） |
| `WIDE_SPAN` | 130 | 区间跨度 > 此值判 WARN（过宽易吞并邻条，参见 PR-001 F4） |
| `MIN_FEATURES` | 4 | 主题特征少于此数则无法可靠判别，降级 SKIP |
| `MIN_SPAN_FOR_COVERAGE` | 5 | 被引原文 < 5 行时跳过覆盖率阻断（见 4.3） |

退出码：`0` PASS ｜ `1` ERROR（阻断）｜ `2` WARN（存疑）｜ `3` 用法错误。

### 4.3 小样本降级（防度量反噬的关键设计）
单行/短行引用（被引原文仅 1~4 行，约 40~200 字），其原文特征基数与 markdown 整条 bullet 主题句严重不对等，覆盖率**天然趋零**——此时低覆盖是"样本不足"而非"张冠李戴"。故 `span < MIN_SPAN_FOR_COVERAGE(5)` 时**只做结构校验＋弱信号提示，不判阻断**（同团队"差异低于噪声带宽不采纳"纪律）。

### 4.4 双低才阻断
`coverage < WARN_COVERAGE 且 term_hit == 0`（bigram 与术语双低）才判 ERROR；若术语有命中则降级 WARN（锚点疑似偏移而非错位）。

### 4.5 三道防误伤豁免
1. **自检清单条目单列档**（`RE_CHECKLIST`）：`- [ ]` 条目措辞为我方作业语言、常隔一层跨域引申（如原文讲 TTS 填充词→落点"不确定性显式标注"），低覆盖属预期，只 WARN 提示须标〔引申〕（与 PR-001 F1「引申与原文分离」同纪律）。
2. **教学性反例引用豁免**（`RE_IGNORE`）：行内加 `<!-- cite-ignore -->` 标记，豁免刻意引用错误锚点作反面教材（如 governance 引 11781–11804 说明何为张冠李戴）。
3. **PR 归档排除**（`DEFAULT_EXCLUDES = ("references/prs",)`）：PR 内保留的历史错误行号是审计留痕，默认排除免生伪阳性。

### 4.6 正则回溯防护
`RE_RANGE` / `RE_SINGLE` 尾部加 `(?!\d)`，防贪婪失败回溯截断出幻觉行号（如"行 13167–13171"被截出假 `1316`）。

### 4.7 评测系统自身可信度
脚本内置 `--self-test`（解析层 5 例＋判别层 6 例，含 B-1 正反锚点 10783→PASS / 11781→ERROR），改动后必须先跑，不过则结论不可采信。另支持 `--calibrate` 输出覆盖率分布（P5/P25/中位/P75），阈值须来自产线数据。
